Parameter Pengujian Migration Agent
1.​ Data Size​
Ukuran data yang dikirim dari Edge ke Cloud, misalnya 100 KB, 500 KB, atau 1 MB.
2.​ Upload Time​
Waktu yang dibutuhkan untuk mengirim data dari Edge ke Cloud.
3.​ Processing Time​
Waktu yang dibutuhkan Cloud untuk memproses data yang diterima.
4.​ Download/Response Time​
Waktu yang dibutuhkan untuk mengirim hasil pemrosesan dari Cloud kembali ke
Edge.
5.​ Total Latency​
Total waktu sejak proses migrasi dimulai sampai hasil diterima Edge.​
Total Latency = Upload Time + Processing Time + Response Time
6.​ Success Rate​
Persentase proses migrasi yang berhasil dari seluruh percobaan.​
Success Rate = (Migrasi Berhasil / Total Percobaan) × 100%
7.​ Failed Migration​
Jumlah proses migrasi yang gagal, beserta penyebab kegagalannya, misalnya
network timeout, server tidak tersedia, atau API error.

Pengujian Keseluruhan

1.​ Integration Testing
2.​ Stress test
3.​ Fault Tolerance
●​ Container mati
●​ Network putus
●​ Cloud service mati
●​ Pod cloud mati (kubernetes)
●​ Pengujian Fault Intolerance bertujuan untuk mengevaluasi ketahanan sistem terhadap
kondisi kegagalan, baik pada sisi aplikasi, server, maupun jaringan. Dalam pengujian ini,
dilakukan simulasi gangguan seperti mematikan salah satu container backend, memutus
koneksi jaringan, atau menghentikan salah satu layanan load balancer secara tiba-tiba.
Sistem diharapkan tetap dapat beroperasi dengan baik, meminimalisir downtime, dan
mendistribusikan beban ke node yang masih aktif. Hasil pengujian fault intolerance akan
menunjukkan seberapa handal sistem dalam menghadapi kegagalan dan memastikan
adanya mekanisme failover yang efektif.
